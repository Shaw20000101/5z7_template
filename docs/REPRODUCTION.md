## 模板自检

要求Python 3.9或更高版本，仅使用标准库，不需要GPU、模型、数据集或第三方安装。

在项目根目录执行：

```bash
python3 scripts/validate_records.py
```

脚本检查骨架、文档本地链接、登记格式与关联、证据文件哈希（若已登记），以及Git数据排除规则。不会执行任务、访问网络、初始化仓库、改文件或提交代码。自检通过只表示维护结构可用。
