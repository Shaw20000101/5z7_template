# 文档分类索引

先用 [项目导航](PROJECT_MAP.md) 定位问题，再沿本页进入相关文档，不必阅读所有历史。

| 类别 | 入口 | 作用 |
|---|---|---|
| 当前任务 | [TASKMEMORY](../TASKMEMORY.md) | 状态、入口、下一步和授权 |
| 项目导航 | [PROJECT_MAP](PROJECT_MAP.md) | 按问题找代码、命令和结果 |
| 项目记忆 | [PROJECT_MEMORY](PROJECT_MEMORY.md) | 当前有效决定与约束 |
| 复现 | [REPRODUCTION](REPRODUCTION.md) | 环境、资源、实际命令与验证范围 |
| 记录规范 | [RECORD_SPEC](RECORD_SPEC.md) | 运行、来源、登记与收据 |
| Git | [GIT_WORKFLOW](GIT_WORKFLOW.md) | 询问保存、审查提交和数据排除 |
| 回复 | [RESPONSE_STYLE](RESPONSE_STYLE.md) | 先简答、再折叠解释 |
| 设计 | [design](design/README.md) | 设计方案和接口取舍 |
| 报告 | [reports](reports/README.md) | 功能、修复、实验和交付结论 |
| 来源 | [provenance](provenance/README.md) | 轻量来源记录 |
| 登记 | [registry](registry/README.md) | 数据、运行、评测、展示关联 |
| 归档 | [archive](archive/README.md) | 历史文档和记忆 |
| 脚本 | [scripts/README](../scripts/README.md) | 可执行入口及输入输出 |

新增专题报告后，在对应分类README加一行结论、状态和链接；关键入口变化同步更新PROJECT_MAP。不要在索引里复制整篇报告。

## 可复制的记录骨架

- [专题报告](templates/REPORT.md)
- [执行计划](templates/PLAN.json)
- [实际执行](templates/EXECUTION.json)
- [交付收据](templates/RECEIPT.json)

这些骨架仅用于填写真正的任务，不能原样登记为完成证据。
