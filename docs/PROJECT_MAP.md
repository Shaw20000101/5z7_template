# 项目导航

## 我应该从哪里开始？

- 了解项目与复制模板：[根README](../README.md)。
- 查看工作约定：[AGENTS](../AGENTS.md)。
- 接续当前任务：[TASKMEMORY](../TASKMEMORY.md)。
- 查询已确定的方案：[项目记忆](PROJECT_MEMORY.md)。
- 找专题文档：[文档索引](README.md)。
- 找可运行入口：[脚本索引](../scripts/README.md)。
- 准备环境或复现：[复现说明](REPRODUCTION.md)。
- 找历史运行与来源：[登记索引](registry/README.md)、[来源索引](provenance/README.md)。
- 查Git与数据排除：[Git工作流](GIT_WORKFLOW.md)。

## 项目实际入口

尚未配置。使用模板后填写实际代码入口、关键配置、已验证命令、最新有效报告及其稳定编号。没有运行或结果时明确写“暂无”，不写虚构链接。

导航只链接当前有效入口；旧结果留在报告与归档中，不通过重命名或覆盖让历史身份变化。
